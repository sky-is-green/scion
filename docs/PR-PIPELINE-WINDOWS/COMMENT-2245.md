One more gfx1100 report for the not-universal side. 2x RX 7900 XT, Linux, ROCm 7.2, engine 0.1.44 (plus a local branch that only adds artifact support, no pipeline changes), `--pipeline-windows 2 --spec 4`, drafter on the last card via the gfx11 default. About 30 requests ran clean: 4K contexts, 128-token outputs on our bench protocol, and one 400-token generation. The `STRATA_MTP_STAGE0=1` arm (drafter on the first card) ran clean as well.

At the reported rate of about 0.7 failures per 100 requests that is one data point, not an absence claim. The conditions differ from the two reports so far (@bcrawford-cpm on Windows/gfx1100, @metzenwest's gfx1030 bisect): Linux with ROCm 7.2, short contexts, and the default `--short-read 64` in use while the reported failure is at the short-read tail.
